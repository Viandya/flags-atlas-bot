# Атлас наизусть

Мини-игра на флаги, страны и столицы для Telegram (Telegram Mini App). Один файл, без бэкенда и внешних запросов — все 195 флагов и контуры карты мира вшиты прямо в HTML.

## Режимы

- **Флаг → страна** — 15 вопросов, узнать страну по флагу.
- **Страна → флаг** — выбрать нужный флаг из четырёх.
- **Столицы** — назвать столицу по флагу и стране.
- **Карта мира** — марафон на все 195 стран: вписываешь название, и страна закрашивается на карте. Принимает разговорные названия («Америка», «Англия», «Голландия» и т. п.), не различает регистр и «ё/е».

Рекорды сохраняются в localStorage браузера (на устройстве игрока).

## Как запустить

Файл `index.html` самодостаточный — можно открыть локально в браузере или разместить на любом статическом хостинге.

### GitHub Pages

1. Settings → Pages → Source → ветка `main`, папка `/ (root)` → Save.
2. Через 1–2 минуты страница будет доступна по адресу:
   ```
   https://<логин>.github.io/<репозиторий>/
   ```

### Подключение к Telegram-боту

1. Создать бота через [@BotFather](https://t.me/BotFather): `/newbot`.
2. `/mybots` → выбрать бота → **Bot Settings** → **Menu Button** → **Configure menu button** → вставить ссылку на страницу.
3. Готово: кнопка меню в чате с ботом открывает игру.

Для полноценного поведения Mini App (тема Telegram, кнопка «Назад», вибро­отклик) в `index.html` перед основным `<script>` нужно подключить:
```html
<script src="https://telegram.org/js/telegram-web-app.js"></script>
```
Код уже проверяет наличие `window.Telegram` и использует эти возможности, если скрипт подключён.

## Структура

```
index.html   — вся игра: разметка, стили, логика, данные о странах, флаги (base64), карта (SVG-контуры)
```

## Данные

- Список стран: 193 члена ООН + Ватикан и Палестина, с кодом ISO, столицей и регионом.
- Флаги: растровые PNG, сгенерированы из [flag-icons](https://github.com/lipis/flag-icons).
- Контуры карты: Natural Earth (через [world-atlas](https://github.com/topojson/world-atlas)), спроецированы Natural Earth 1.
